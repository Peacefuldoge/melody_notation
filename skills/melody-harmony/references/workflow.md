# AI 配和弦工作流程 | Harmonization workflow

目标：让 Agent 能**解释、提案、验证**和声设计，即使当前 Melody Notation 仍是单旋律简谱引擎。

## 1. 理解任务与边界

提取用户的：曲名/旋律文件、调号和转调、拍号、BPM、目标风格、情绪词、主奏乐器、伴奏密度、参考的和弦进行、是否允许改变旋律。若信息缺失，从可用内容做保守假设并注明。情绪和弦映射**只给出倾向与依据**。

对于既有 `.jianpu`，可调用 `inspect_score` 获取音符和节拍，留意 `key_changes`；**不要用转调前的调对整个乐段自动配和弦**。对跨小节长音、休止和附点核对强拍实际位置。未经明确授权不要修改原谱。

## 2. 旋律分析

1. 按小节记录强拍旋律音、时值、终止/重复点；注意高八度点、升降记号。
2. 判断可能调性与和声节奏：通常先试每小节一和弦，再试每两拍一和弦，避免为了“复杂”而频繁变和弦。
3. 对每个强拍音列出两到三个候选和弦：优先包含它为根、三、五、七的和弦；若落在 9、挂留/非和弦音，解释解决路径。
4. 优先顺畅声部进行：保留共同音，其他音就近移动；检查导音/七度的倾向，不用机械规定所有流行音乐必须遵守古典规则。
5. 低音有独立方向；选 `C/E` 之类的转位可优化下行线，但不能用它更改和弦功能。

## 3. 输出两套建议

- **基础版**：三和弦/简单七和弦，功能清晰、容易试听和理解。
- **色彩版**：在基础上少量加入 maj7、add9、sus、借用 iv、V7/vi 等。每一次替换说出旋律匹配和功能影响。
- 明确哪几小节建立紧张，哪几小节释放；标出可能刺耳的低音拥挤或旋律/和弦冲突。
- 如果用户要“中国风”“武侠”“Game Boy”，和弦只是一个参数。优先考虑五声音阶、节奏动机、音区/分解型、低音与乐器包络等，不要认为某一种和弦就是某个文化风格。

## 4. 编配：可执行但不冒充多轨

当前版本 Melody Notation 支持**单旋律编辑、MIDI/音频/PNG 导出**；暂不支持同时播放多个和弦音轨。因而：

- 输出 `*.harmony.md`（或结构化提案），把“每小节建议和弦 / 转位 / 理由 / 伴奏型 / 乐器建议”记录为可审查计划。**不要写成未受支持的 `.jianpu` 多音符垂直和弦语法**。
- 需要听完整伴奏时，建议用户将旋律 MIDI 导入 DAW，另建和弦轨；也可在后续多轨引擎实现后复用这些提案。
- 若用户仅要一段和弦音的单轨旋律，可建议使用分解和弦的逐音符旋律，但需遵守拍号、保持现有 melody 文件语法；不要声称已生成同时发声的和弦。
- 对 Codex：使用本 Skill 的 `chords.md`、`progressions.md`、`sources.md`。
- 对 DeepSeek Harness：先调用只读 `list_harmony_topics`，再用 `read_harmony_guide(topic)` 读取对应知识；它不会自动“训练”模型权重。

## 5. 质量检查清单（每次作曲建议输出前）

- [ ] 已记录调号、变调点、拍号、目标速度，避免半音/大小调混淆。
- [ ] 和弦的三度/七度质量正确（Cmaj7 ≠ C7；m7♭5 ≠ dim7）。
- [ ] 罗马数字与绝对和弦名在所选调里正确。
- [ ] 副属和弦、借用和弦有解释；外来音不是错误拼写。
- [ ] 强拍重要旋律音被和弦解释；不和谐音有实际解决或有意保留。
- [ ] 和声节奏合理，不随意盖过旋律。
- [ ] 建议含两套并说明取舍，情绪是“可能呈现”而不是“必然造成”。
- [ ] 不修改已有用户文件；若将提案落盘，使用新文件名并征求用户对覆盖操作的确认。

## 6. 输出模板（可复制）

```markdown
# [作品] 和弦方案（建议，不改变原简谱）
- Key：C major；4/4；120 BPM；目标：温暖、带一点悬念
- 和声节奏：每小节 1 和弦

| 小节 | 主要旋律音 | 基础版 | 色彩版 | 作用/注意 |
|---|---|---|---|---|
| 1 | E, G | C | Cadd9 | I，旋律 E/G 是和弦音 |
| 2 | D, G | G | Gsus4 → G | V，F→E 的解决需核对实际旋律 |
| 3 | C, E | Am | Am7 | vi，缓和情绪 |
| 4 | A, C | F | Fmaj7 | IV，向下一句开放 |

伴奏建议：钢琴分解和弦（1、5、3、5），低音根音每小节一次。
注意：当前程序无法原生混合和弦轨；这是等待多轨实现的计划。
```

## 7. 常见错误

- 把 `7` 当作大七（实际上 **C7 是属七**，含 B♭）。
- 把 `sus4` 当作在三和弦上添加 4（它通常**替换三度**）。
- 把 `C9` 当作 `Cadd9`（C9 含 B♭）。
- 用“悲伤=小调和弦”机械判定而不看音区、速度、进行与文化语境。
- 忘记检查旋律的持续音在和弦切换时成为张力音的可能性。
- 使用现有单旋律引擎导出文件，却告诉用户里面已经有完整和弦伴奏。
