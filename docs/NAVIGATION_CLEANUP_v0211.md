# v0.2.11 导航去重说明

## 改动内容

- 左侧标题保持纯品牌文字，不再作为菜单入口。
- 文件 / 编辑 / 导出 / 工具四个按钮是侧栏展开时唯一完整操作菜单。
- 移除没有明确目标的主页按钮。
- 独立保存按钮移除；「保存」「另存为」归并至文件菜单（Ctrl+S / Ctrl+Shift+S）。
- 展开侧栏：显示新建简谱文字入口；窄栏的新建和更多入口隐藏。
- 折叠侧栏：文字入口隐藏；窄栏显示新建和更多，确保仍可访问所有操作。
- 保留项目行中的 `+`（新建项目）及 `…`（项目专属操作），它们与全局文件菜单职责不同。

## 不变部分

- Tkinter、浅色和深色主题
- 项目树、多标签、自动保存保护、内置示例
- 音乐引擎、音色、倍速、试听、MIDI/PNG/音频导出
- MCP / Codex / DeepSeek Harness 接口

## 测试

- `python -m pytest -q`
- `xvfb-run -a python devtools/sidebar_cleanup_smoke.py` （Linux GUI 冒烟测试）
- Windows 使用 Conda 原环境即可安装，本机渲染与交互仍建议复核。
