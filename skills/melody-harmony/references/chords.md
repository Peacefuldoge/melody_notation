# 常见和弦辞典 | Chord vocabulary

这是**创作参考**而不是“某和弦必然对应某情绪”的规定。表中的情绪是常见聆听联想；调式、速度、配器、音区、节奏、前后进行及文化背景会显著改变听感。

## 读法与核心概念

- C 大调三和弦 **C = C–E–G**；Cm = C–E♭–G；C7 = C–E–G–B♭；Cmaj7 = C–E–G–B。**C7 不是 Cmaj7**。
- `add9` 在三和弦上加九度（例如 Cadd9 = C–E–G–D），**不自动加七度**；`9` 通常表示包含七度的属九和弦（C9 = C–E–G–B♭–D）。
- `sus2` 与 `sus4` 通常用二度/四度**代替三度**；不是“大三和弦加二/四度”。
- 转位用斜杠表示最低音，如 `C/E` = 低音 E，上方仍为 C 和弦；转位并不改变和弦根音。`C/G` 是第二转位。
- 下表以根音 C 举例，**移调时所有和弦音一起平移**。例如 Cmaj7 → Dmaj7 为 D–F♯–A–C♯。
- 半音间隔以 C=0 算，`14` 是高八度的二度，`17` 是十一度。实际编配允许省略重复八度与不重要的五度；增减变化必须保留决定音色/功能的音。

## 三和弦、挂留与加音（适用于流行、民谣、电子、8-bit）

| 和弦 | 以 C 为根的构成音 | 典型联想（非硬性规则） | 常见使用方式 / 注意 |
|---|---|---|---|
| C / maj | C E G | 明亮、坚定、安定 | 大调 I/IV/V；终止落点；简单芯片音色分解和弦 |
| Cm / m | C E♭ G | 内省、温柔、沉郁 | 小调 i、iv、v；和弦持续音；不等于必定“悲伤” |
| C5 / power | C G | 中性、直接、有力量 | 摇滚/8-bit 强节奏；缺少三度，调式由旋律决定 |
| Cdim / ° | C E♭ G♭ | 不稳、悬疑、急促 | 引导到半音邻近目标；常在 vii° 或经过和弦，避免无目的长时间停留 |
| Caug / + | C E G♯ | 漂浮、奇异、期待变化 | 增五度趋向邻音；过渡或电影配乐，不必强行解决 |
| Csus2 | C D G | 开阔、朦胧、青春感 | 前奏、氛围铺底；无三度，可保持开放感 |
| Csus4 | C F G | 悬而未决、庄重、期待 | 常 Csus4→C（F→E）；现代风格也可不解决 |
| Cadd9 | C E G D | 温暖、清澈、怀旧 | 流行/民谣、游戏场景，适合唱片尾/抒情主歌 |
| Cm(add9) | C E♭ G D | 忧郁、精致、空灵 | 慢板、氛围配器；避免旋律与 D/E♭ 在密集低音区冲突 |
| C6 | C E G A | 轻松、复古、柔和 | 爵士、摇摆、结尾替代 Cmaj7；与 Am7 有相同音集合、低音决定听感 |
| Cm6 | C E♭ G A | 苦甜、复古、含蓄张力 | 爵士/电影配乐；A 是大六度，不是 A♭ |
| C6/9 | C E G A D | 通透、精巧、平和 | 无明显大七度导音拉力的柔和终止；适合高音区 |

## 七和弦、延伸和弦（适用于流行、爵士、R&B、Lo-fi）

| 和弦 | 以 C 为根的构成音 | 典型联想 | 常见使用方式 / 注意 |
|---|---|---|---|
| Cmaj7 | C E G B | 柔和、浪漫、宽阔 | 大调 Imaj7/IVmaj7；旋律主音 C 与 B 相邻时留意摩擦 |
| C7 | C E G B♭ | 推进、蓝调、期待解决 | **属七**多作 V7→I；亦可作蓝调 I7，功能取决于上下文 |
| Cm7 | C E♭ G B♭ | 温柔、惆怅、松弛 | ii7 / vi7 / i7；Lo-fi / 爵士循环 |
| Cm(maj7) | C E♭ G B | 神秘、电影感、纠结 | 旋律小调语境；B 与 C 形成半音张力 |
| Cm7♭5 / Cø7 | C E♭ G♭ B♭ | 脆弱、悬念、待解决 | 小调 iiø7–V7–i 中的前属准备 |
| Cdim7 / C°7 | C E♭ G♭ B𝄫(等音 A) | 尖锐、戏剧、转场 | 对称减七，可作导向/经过；转位解析依调性 |
| Caug7 / C7♯5 | C E G♯ B♭ | 强烈、奇特、悬而未决 | 属和弦变化音；♯5 往往逐步解决 |
| C9 | C E G B♭ D | 浓郁、活跃、蓝调 | C7 的延伸，适合 funk / jazz；保留 E 与 B♭ |
| Cmaj9 | C E G B D | 梦幻、细腻、松弛 | 大调 Imaj9/IVmaj9，抒情与氛围；高音区展开 |
| Cm9 | C E♭ G B♭ D | 深沉、温润、夜晚氛围 | 爵士 / Neo-soul / Lo-fi；注意低音区避免密集浑浊 |
| C11 | C E G B♭ D F | 浓重、悬浮、复杂 | 属十一完整堆叠里 E/F 小二度冲突；实用配器常省三度 |
| Cm11 | C E♭ G B♭ D F | 迷离、舒展、忧郁 | 小调氛围背景，允许省根音以免拥挤 |
| C13 | C E G B♭ D (F) A | 丰富、律动、都市感 | 属十三常省 5、11，保留 3、♭7、13；如 G13→Cmaj9 |
| C9sus4 / C7sus4(9) | C F G B♭ D | 开放、蓄势、宽阔 | 属挂留声音；常到 C7 或 F，但也能延续 |
| C7♭9 | C E G B♭ D♭ | 强张力、紧迫、古典/爵士终止 | 常用于小调 V7♭9→i；D♭ 会趋向 C |
| C7♯9 | C E G B♭ D♯ | 粗粝、激情、布鲁斯感 | 摇滚 / fusion / altered dominant；D♯ 与 E 的拼写关系不可忽略 |
| Cmaj7♯11 | C E G B F♯ | 闪亮、漂浮、电影感 | Lydian 色彩；第四级升高，常用上层开放排列 |

## 功能视角：比“情绪标签”更重要

- **主功能 Tonic (T)**：I、vi、iii（大小调需辨析），稳定/归属；例如 C、Am、Em 在 C 大调中常作不同程度的主功能延伸。
- **前属功能 Predominant (PD)**：ii、IV（小调 iiø / iv），准备强属；例如 Dm7 → G7。
- **属功能 Dominant (D)**：V、V7、vii°，导向主和弦；例如 G7 → C。流行摇滚不一定要求每次解决。
- **替代属/副属**：如在 C 大调里 E7 是 V7/vi，短暂增强指向 Am 的张力。**出现 E7 不等于整曲转 A 小调**。
- **借用和弦 Modal mixture**：在 C 大调中借平行小调的 Fm（iv）、A♭（♭VI）、B♭（♭VII），可制造苦甜、阴影、史诗色彩。借用不自动意味着转调。
- **半音连接**：低音线 C–B–A 可由 C–G/B–Am 达成，减少跳进；和弦的故事取决于低音和内声运动。

## 选和弦时的快检表

1. 确定旋律强拍音是否为和弦音（1/3/5/7/9），或者有清楚的经过音/邻音解释。
2. 记录每个和弦的功能（T/PD/D/借用/色彩），不要仅靠情绪标签乱堆。
3. 尽量让内声保持共同音、其他声部就近移动；有意的跳进应有音乐理由。
4. 先用三和弦给旋律配底，再渐进加入 7、9、11、13；低音区少堆延伸音。
5. 提供至少两种选择（朴素版、色彩版），对比试听后由用户选择。
