# DAW 多轨工作台交互改版（兼容 v0.4.3）

本轮把原先过小的只读时间线、音轨表格和巨大片段表格重构为一个主编辑区：

- 左侧常驻音轨头：轨道名、类型/音色、M（静音）与 S（独奏）。
- 右侧主时间线：小节网格、彩色片段、选中描边与水平/垂直滚动。
- 直接编辑：点击选择，水平拖动移动；拖两端裁剪；Ctrl+拖动复制；双击打开源文件。
- 右键菜单：当前位置切割、复制、打开源文件、删除片段。
- 工具栏：添加素材、复制、切割、删除，吸附粒度、缩放与适应窗口。
- 下方只留紧凑片段属性条：位置、裁剪、增益与反转。
- 已选轨道 M/S 与右侧轨道音色检查器同步；已有 Undo/Redo 快照保留。
- 直接编辑使用项目现有 `.mtrack` beat 单位，不修改源 `.jianpu` / `.drum`。
- 在已有音轨追加素材时，默认追加到最后一个片段之后，不再全部叠到第 1 拍。

## 使用提示

1. 在项目树双击 `.mtrack` 打开多轨工程。
2. 「添加素材」选择项目内 `.jianpu` 或 `.drum`；若当前音轨同类型，会询问追加到该轨末尾。
3. 在片段主体拖动以移动；边缘拖动以裁剪；`Ctrl`+拖动以复制。
4. `Ctrl`+鼠标滚轮缩放；右键片段可按鼠标所在拍点切割。
5. 点击左侧 M/S 可即时静音/独奏；精确增益及源文件反转在下方片段属性操作。
6. `Ctrl+D` 复制选中片段；`Ctrl+E` 从中间切开；`Delete` 删除。

## 当前边界

- 时间线是 MIDI/节拍事件片段（非 PCM 录音），未绘制真实音频波形。
- `.mtrack` 没有拍号字段，因此网格目前按 4 拍/小节绘制，时间值仍以拍为准。
- 不涉及自动化曲线、实时波形缓存、多重音频设备路由；需另期独立设计。
- Qt GUI 测试需安装 PySide6；纯编辑逻辑不依赖 Qt。

## 设计参考

交互借鉴了 Ableton Live 的 Arrangement View 设计思路：连续时间轴、轨道级状态、片段直接拖动与边缘裁剪、吸附网格、上下文切割、缩放与导航。不是复制 Ableton 的控件或视觉素材。

参考：<https://www.ableton.com/en/manual/arrangement-view/>

## 变更文件

- `src/qt_gui.py`：新的时间线、轨道头、片段属性栏与交互
- `src/timeline_ops.py`：与 UI 解耦的移动、裁剪、切割规则
- `src/qt_design.py`：适配四套主题的 DAW 控件样式
- `tests/test_daw_timeline_ops.py`：核心编辑算法测试
- `tests/test_daw_qt_smoke.py`：PySide6 可用时运行的 UI 集成烟雾测试

**注意：** 本次运行环境没有 PySide6 包，且无法从网络下载安装，所以没有完成 Qt 实机视觉测试；已通过语法检查及不依赖 Qt 的完整自动测试。建议先在你的 Windows 本机确认缩放、M/S、片段拖动及播放，然后再逐步增加高级功能。
