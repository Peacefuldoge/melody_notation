# v0.5.1 — 快速演奏转谱与谱面布局修复

## 用户现象

在钢琴键盘上快速连续弹奏时，谱面上大量短音符和 `0` 休止符被强行塞入每行 3 个小节，数字和下划线相互覆盖。每次按/松键还会同步重绘整张谱子，可能增加界面事件积压。

## 修复机制

1. **量化精度**：默认 1/4 拍（16 分音符），同次录音中发现相邻独立起音间隔小于 1/4 拍时，使用 1/8 拍（32 分音符）；不改变用户设定的 BPM。单声部简谱仍有最小可表达时长，极端快速演奏可能会在谱面上顺延音符，而原始 MIDI 不受影响。
2. **短间隙处理**：连续音符之间不超过 `min(0.15 s, 0.30 beat)` 的实际键间空隙按连贯乐句记谱，避免出现大量短休止符；超过阈值的真实停顿仍记为 `0`。
3. **动态小节宽度**：以每音符至少 62 个绘图像素分配空间；**v0.5.10 起**：「每行小节」是严格数量，不再因音符密集而提前换行。若指定小节总宽度超过普通谱纸宽度，画布加宽并允许水平滚动；不足数量的末行靠左排版。
4. **重绘合并**：首个输入立即显示；后续最频繁每 100 ms 更新整谱，结束录制必定进行最终刷新，录制时间戳不受界面重绘影响。
5. **格式兼容**：所有内容仍保存为原有 `.jianpu`，真实的力度/复音/时间信息仅通过「导出录制 MIDI」完整保留。

## 录制建议

使用与演奏接近的 BPM。32 分音符以下的极短动作、超复杂和弦、踏板控制等超出单声部简谱表达能力；建议保留一份原始 MIDI，以便以后使用多声部编辑器处理。
