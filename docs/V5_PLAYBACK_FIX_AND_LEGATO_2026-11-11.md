# Melody Notation v0.4.3 · V5 修复说明

## 1. 打开多音轨工程报错

**现象**：单击 `主题编排.mtrack`，弹出 `name 'major' is not defined`。

**原因**：v4 时间线重绘过程中，`major` 变量被用于判断主刻度与小节号，未初始化。

**修复**：在时间线绘制局部明确设定 `major=4`（`.mtrack` v1 仅有 BPM，没有拍号字段，沿用四拍一小节）。保留文件数据格式，不改变时间刻度与已有片段位置。

## 2. 合成期间播放按钮的旋转进度

- 点击播放，后台使用 `ThreadPoolExecutor` 合成 WAV，播放按钮即时显示 `合成中…` 和 12 段圆角辐条旋转图标。
- 动画由主线程 `QTimer` 每 85 ms 更新；底层音频生成继续在工作线程执行，不阻塞鼠标与窗口响应。
- 点击 **停止**、切换标签页、合成失败或完成时，动画立即复位。
- 后台仍在合成时重复点击播放不会启动第二项任务；旧任务结果依靠 `_render_id` 判定丢弃。
- 四种主题的动画颜色跟随按钮前景色；不需要额外图片资源。

## 3. 音色与乐句连续性

**旧问题**：钢琴和吉他包络的 sustain=0，decay≈70ms，虽然音符在谱面上应持续 0.5s 左右，音色却只响了最初几十毫秒。

**修复**：`_tone()` 按音色设置按键阶段的持续包络和尾部释放（release），尾音允许自然与下一音符叠加。不同乐器的起音、持续衰减、释放特性分开设计，并为极短装饰音压缩释放时间。保持 `.jianpu` 的 note-on、note-off 时间和 MIDI 导出不变；只有 WAV 内置预览合成方式改变。

**多轨混音**：与简谱试听保持一致的短尾音缓冲，并加入很轻微的整体空间感；没有改变 clip 起始拍、裁剪值或轨道增益。

**限制**：内置的是轻量程序式合成器，音色虽改善仍不等于真实录音采样或专业 SF2 音源。

## 4. Windows 复核清单

1. 安装依赖并运行 `python -m melody_notation.cli gui`，双击左侧 `主题编排.mtrack`，检查时间线是否出现并支持 M/S、移动和裁剪。
2. 点击右侧播放，合成期间应看到播放按钮旋转，合成完成变为“暂停”；点击“停止”可中断等待/停止播放。
3. 试听 `山风.jianpu` 的钢琴、长笛、吉他，再切换 `.mtrack` 编排试听，检查每个音符不再短促中断。
4. 切换主题（橄榄绿 / 深色）、切换标签页、关闭文件后检查按钮是否正确复位。

推荐在旧目录以外解压新版，以防本地有自定义修改。运行：

```powershell
python -m pip install -e ".[gui,test]"
python -m melody_notation.cli gui
```

这轮没有提升 package 语义版本号，仍保持 `0.4.3`，作为 V5 修复迭代。
