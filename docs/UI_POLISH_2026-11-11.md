# Melody Notation v0.4.3 — UI polish (2026-11-11)

Request: use the user's Windows screenshot as design reference, remove the duplicate horizontal header under the menu, eliminate the oversized filled inspector background under note controls, and show version information at the bottom-right.

Implementation:

1. `MelodyMainWindow.__init__` no longer constructs `TopChrome` or a duplicate current-file title. The native window title, regular menu bar and document tabs remain. The inspector toggle stays accessible as the top-right `QTabWidget` corner widget, via `Ctrl+I`, and via the View menu.
2. `_make_inspector` uses non-stretching properties `QGroupBox`, a normal expanding layout spacer beneath the two cards, and page/stack widgets styled transparently. The right sidebar background matches the existing theme instead of being overlaid by a tall property card.
3. `statusBar().addPermanentWidget` shows the installed `melody_notation.__version__` in the bottom-right; the label is not dependent on inspector visibility. Transient status messages continue on the left.
4. No data model, audio engine, MIDI, MCP or workspace behavior changed.

Validation: `python -m pytest -q`, `python devtools/qt_codex_layout_smoke.py` on Windows with PySide6 installed. If the first run has old user appearance settings, the retained settings might select a different theme; this revision honors all four themes.

## Second pass — native caption and minimal controls

Based on the 1522×972 Windows screenshot, the next changes are:

1. `qt_design.apply_native_chrome()` now sets Windows 11 DWM caption/background (`DWMWA_CAPTION_COLOR=35`), caption text (`DWMWA_TEXT_COLOR=36`) and frame border (`DWMWA_BORDER_COLOR=34`) from the active theme tokens. The pre-existing native backdrop (`DWMWA_SYSTEMBACKDROP_TYPE=38`) remains requested with the user's *Window material* preference. Native titlebar minimize/maximize/close and Snap Layouts stay intact. DWM may render a solid caption tint when an exact color is specified; the app does not claim perfect simultaneous translucency and an exact color match, which Windows does not promise via these attributes. Windows 10/unsupported OS fall back safely.
2. The three ugly native dropdown triangles attached to the left-rail +, New music file and Project actions buttons are removed by using plain QToolButton click-triggered QMenu popups. All menu actions remain operational. An additional QSS rule prevents accidental reintroduction of the auto menu indicator.
3. QSpinBox / QDoubleSpinBox use borderless, transparent up/down buttons with subtle hover/pressed fills and flat corners, instead of embossed Windows steppers. Numeric editing, spin arrows, wheel and keyboard behavior remain unchanged.
4. Added `tests/test_native_chrome_polish.py` to verify Win32 COLORREF mapping, DWM attributes, missing arrow bindings, and theme styles.

Smoke check on Windows: run `python -m melody_notation.cli gui`, switch Appearance themes while the window is open, inspect caption and spin controls, open all three popup menus, then disable/re-enable native material in Settings. Material and blur depend on Windows version and personalization/transparency settings.
