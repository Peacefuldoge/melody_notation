# Melody Notation v0.5.2 — 实时演奏与简谱录制

## 界面位置

仅在 `.jianpu` 简谱标签页底部显示「钢琴键盘 · 演奏与录制」面板，默认展开，可点击标题折叠。打开「显示源码」时，源码编辑器位于钢琴键盘正上方；鼓点 `.drum` 与多轨 `.mtrack` 标签页不会显示琴键。

四种主题：浅色（白/黑）、深色（雾蓝/深蓝）、米色（奶白/咖啡）、橄榄绿（浅绿/深绿）。虚拟键盘覆盖 C4 到 C6，可用鼠标点击和拖奏。

## 电脑键盘演奏

默认：A W S E D F T G Y H U J K O L P ; ' ] \\ 对应 C4–G5 的半音排列，可在「键位设置」里为 C4–C6 任意音符自定义单个键位，支持解绑已有键位并改绑。设置保存于当前用户 QSettings。输入焦点位于文字框、简谱源码、数字输入框或弹出对话框时不会拦截打字；同时按 Ctrl/Alt/Meta 不会触发演奏。自动重复按键不产生额外音符。

## 连接 USB MIDI 控制器与电子乐器

通过 Windows MIDI 输入接口（`mido` + `python-rtmidi`）接收标准 MIDI `note_on`/`note_off` 事件。将电子琴/数字钢琴设置为 USB-MIDI 模式并接到电脑，软件默认每 2 秒刷新输入设备列表；在「自动检测」模式下连接第一个可用输入端口，设备拔出会关闭该端口，重新连接后自动恢复。也可以在设备列表里手动选择某个输入设备、选择仅电脑键盘或点击刷新。

**注意**：有些带 USB-Audio 功能的乐器并不暴露标准 MIDI 输入端口，需要安装厂商的 MIDI 驱动或配置 USB-MIDI 模式。USB 音频输入不属于本功能。

## 录制、转谱及 MIDI

1. 新建空白简谱，设置乐曲速度和调号。
2. 展开底部钢琴，按「● 开始录制」。第一个音符按下时开始计时；在此之前不插入长串休止符。
3. 用电脑键盘、鼠标或外接 MIDI 乐器演奏。按键时即时在简谱显示音符，松键时更新量化后的时值。真实停顿转成休止符，极短换键间隙自动连接，末尾补全当前小节。
4. 按「■ 结束录制」。整次录制作为一个可撤销操作。使用 File > Save 保存 `.jianpu`。
5. 想导出精确原始演奏，请点击面板「导出录制 MIDI」，将当前这次演奏保存为 `.mid`，保留复音和力度。顶部菜单的 MIDI 导出依然对应当前简谱（量化后的单旋律）。

**限制**：现有 `.jianpu` 是单声部表示，v0.5.2 默认以 1/4 拍网格转谱，检测到快速连续起音时自动使用 1/8 拍（32 分音符）精度，并对短暂换键间隙做自然衔接。重叠按键时简谱选择一个旋律声部，后续起音会截短前面的持续音；原始演奏 MIDI 可以保留和弦、力度、精细的时间信息。表情控制器（例如弯音、延音踏板、aftertouch）暂未写入原始 MIDI；建议录制结束后立即导出原始 MIDI，以免下一次录制覆盖此缓存。

## 安装与启动

```powershell
conda activate melody
cd D:\Work\melody_notation
python -m pip install -e ".[gui,test]"
python -m melody_notation.cli gui
```

`gui` 依赖包含 `PySide6`、`mido`、`python-rtmidi` 和 `sounddevice`。未找到音频输出设备或没有声卡时，实时监听会提示不可用，但简谱录制和 MIDI 导出仍然可用。SDK MCP 仅支持 2.x；项目根目录 `melody_notation`、源码目录 `src` 保持不变。

## v0.5.2 键盘音色

在简谱底部钢琴的第二行「键盘音色」下拉框切换实时键盘发声音色；它不影响右侧的乐谱播放/导出音色。录制的原始 MIDI 导出时，使用当前键盘音色对应的 GM program；录制数据本身仍保留原始音高、时值及力度。切换音色时会释放正在按下的琴键，避免悬挂的声音。

项目侧栏左上角「展开／收起项目侧栏」现在会一起收缩外层导航分隔面板，折叠状态下只保留 54px 图标栏。
