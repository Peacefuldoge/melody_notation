# 和弦进行配方 | Progressions in context

**读法**：`I / ii / V7 / ♭VI` 是相对于调性的罗马数字；示例以 **C 大调** 或 **A 小调** 为主。小调表里 `V7 = E7` 来自和声小调升高的导音（G♯），不是 A 自然小调原生的 Em7。每个方格通常可以放一小节，也能按节奏拆成两个半小节。情绪只能作为探索起点。

## 大调与流行（C major）

| 目标或气氛 | 进行（罗马数字） | 实际和弦 | 做法 |
|---|---|---|---|
| 熟悉、明亮、流畅 | I–V–vi–IV | C–G–Am–F | 主歌、游戏主题，旋律强拍先吻合和弦 |
| 怀旧、经典流行 | I–vi–IV–V | C–Am–F–G | 50s/doo-wop；末尾 G7 可增加回归张力 |
| 温暖而有一点惆怅 | vi–IV–I–V | Am–F–C–G | 从 vi 开始可弱化主调的明亮度 |
| 直接、有归属感 | I–IV–V–I | C–F–G–C | 适合短小主题与 8-bit 关卡；分解演奏易于实现 |
| 细腻连贯 | I–iii–vi–IV | C–Em–Am–F | 共享音较多，可使内声顺滑 |
| 爵士式解决 | ii7–V7–Imaj7 | Dm7–G7–Cmaj7 | G7 的 B 和 F 分别往 C / E 解决 |
| 温柔、悬而未决 | Iadd9–Vsus4–vi7–IVmaj7 | Cadd9–Gsus4–Am7–Fmaj7 | 开放挂留与 9 度；避免低音区密堆 |
| 夜色/Neo-soul 色彩 | Imaj9–vi9–ii9–V13 | Cmaj9–Am9–Dm9–G13 | 键盘常用紧凑上层结构；伴奏需分声部 |
| 先惊讶再回归 | I–V7/vi–vi–IV | C–E7–Am–F | E7 增强指向 Am 的色彩，是副属不是自动转调 |
| 电影感的苦甜转折 | I–IV–iv–I | C–F–Fm–C | 平行小调借用 iv，A→A♭→G 的内声线很重要 |
| 史诗式大调攀升 | ♭VI–♭VII–I | A♭–B♭–C | 需要旋律和节奏支持；常用作有力的终止/进入副歌 |
| Rock / Mixolydian 色彩 | I–♭VII–IV–I | C–B♭–F–C | ♭VII 是风格色彩，不必每次依传统属功能解决 |
| 假终止、继续期待 | IV–V–vi–V | F–G–Am–G | G→Am 为 V→vi 的意外转向；下一轮可回 C |

## 小调与戏剧（A minor）

| 目标或气氛 | 进行（罗马数字） | 实际和弦 | 做法 |
|---|---|---|---|
| 叙事、深沉又可展开 | i–♭VI–♭III–♭VII | Am–F–C–G | 广泛用于游戏/影视/流行；并不一定悲伤 |
| 推进、传统小调终止 | i–iv–V7–i | Am–Dm–E7–Am | G♯ 导向 A；终止清晰 |
| 下行、悲壮感 | i–♭VII–♭VI–V7 | Am–G–F–E7 | 低音 A–G–F–E 的线条是重点 |
| 循环、探索感 | i–v–♭VI–♭VII | Am–Em–F–G | 自然小调色彩，少了 E7 强烈导音 |
| 张力与异域感 | i–♭II–V7–i | Am–B♭–E7–Am | ♭II 可作强色彩借用，适合悬疑或关卡 Boss；注意旋律冲突 |
| 轻微而开放的忧郁 | i7–iv7–♭VII7–♭IIImaj7 | Am7–Dm7–G7–Cmaj7 | 循环可以暂时像 C 大调 ii–V–I，表达双重中心 |
| 调性对比的终止 | i–iv–V7–I | Am–Dm–E7–A | 末尾 A **大三和弦**是 Picardy third 色彩，存在 C♯ |
| 快速芯片冒险 | i–♭VI–♭VII–i | Am–F–G–Am | 三和弦/双音分解演奏最容易适配有限声部 |

## 常见功能链条（换调时优先用此表）

- 结束感强：`ii–V7–I` 或小调 `iiø7–V7♭9–i`。
- 开放循环：`I–V–vi–IV`，不必每次回 I 停顿。
- 暂时强化目标和弦：`V7/vi–vi`，`V7/V–V`，不要把 **V/V** 当作五级和弦本身。
- 借用制造阴影：`IV–iv–I`、`♭VI–♭VII–I`。
- 用挂留延迟解决：`Vsus4–V–I`，或大调 `Iadd9–IVmaj7`。
- 用转位平顺低音：`I–V/3–vi` 在 C 大调是 C–G/B–Am，低音 C→B→A。

## 速度/编曲建议：同一进行，不同效果

- **88 BPM + 轻柔钢琴 + 长时值**：`Am–F–C–G` 更像叙事与回忆。
- **160 BPM + 8-bit 脉冲波 + 短音分解**：同一 `Am–F–C–G` 可能偏动作、冒险或紧张。
- **慢速 + pad 持续 + add9/maj9**：更朦胧；旋律的非和弦音需要检查解决方向。
- **快节奏 + 7th/9th 切分**：更爵士/R&B，但须避免高密度音符挤占主旋律。

**重要**：这些是原创示例模板，不是任何特定歌曲的完整和弦转录。不要把配方当作风格的唯一公式；给用户两套替代并让用户试听选择。
